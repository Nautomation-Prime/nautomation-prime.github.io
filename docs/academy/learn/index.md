## The path

<div class="grid cards" markdown>

-   ### 1. Beginner

    Your first Netmiko scripts: run a command, scale it across devices, back up configs.

    [Beginner tutorials](../../foundation/tutorials/beginner/index.md)

-   ### 2. Intermediate

    One technique per page: YAML and Pydantic, Jinja2, Nornir, PyATS, credentials, logging, rollback, pre-flight checks.

    [Intermediate tutorials](../../foundation/tutorials/intermediate/index.md)

-   ### 3. Build netpipe: the Capstone

    Seven chapters, one repository. Put the intermediate techniques in a line and make them hold: a deployment pipeline that validates, renders, deploys, proves and rolls back a real change.

    [Build netpipe](../../foundation/tutorials/capstone/index.md)

-   ### 4. Expert

    What changes at scale: asyncio, circuit breakers, dependency ordering, vaulting, observability, incident response.

    [Expert tutorials](../../foundation/tutorials/expert/index.md)
